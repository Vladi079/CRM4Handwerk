# Screenshots

Hier gehören die Bilder für die Haupt-`README.md` hin.

- **`screenshot.png`** — das Titelbild, das die README oben einbindet. Ein guter
  Kandidat ist das **Kanban-Board** unter _Aufträge_ (angemeldet, mit ein paar
  Beispiel-Aufträgen). Empfohlen: Desktop-Breite, heller Modus, ~1280 px breit.

So erstellst du es: App starten (siehe README), anmelden, ein paar Kunden und
Aufträge anlegen, Status verteilen, dann einen Screenshot des Boards machen und
hier als `screenshot.png` ablegen.

Optional für eine lebendigere README: eine kurze GIF-Aufnahme, wie eine Karte
per Dropdown den Status wechselt.
